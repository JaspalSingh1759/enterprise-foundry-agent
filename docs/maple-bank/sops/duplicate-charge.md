# SOP: Handling a duplicate charge

**Policy:** Card Dispute Policy 4.2 and 3.1. **Network reason code:** NS-12.1.

## When to use

The customer says they were charged more than once for one purchase.

## Steps

1. Open the case and note the merchant, amount and date from the claim.
2. List the card's transactions around that date for that merchant.
3. Confirm the duplicates: same merchant, same amount, same transaction date. Note both transaction IDs.
4. If the customer attached a receipt, check it shows **one** purchase of that amount.
5. Check the time limit with the rules tool (policy 3.1).
6. Recommend a credit for the **extra** charge only. The first charge stands.
7. If the amounts or dates differ, it is not a duplicate: check whether it is two separate purchases, and ask the customer if unsure.

## Common mistakes

- Crediting both charges. Only the extra one is credited.
- Treating a pre-authorisation that later posted once as a duplicate. Only **posted** charges count.
