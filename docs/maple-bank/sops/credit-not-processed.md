# SOP: Handling a credit not processed

**Policy:** Card Dispute Policy 4.4 and 3.1. **Network reason code:** NS-13.6.

## When to use

The customer returned goods or cancelled a service and has not been refunded.

## Steps

1. Find the original purchase on the card.
2. Read the proof of return (return slip). No proof: **request information**.
3. Note the return date and the refund amount on the slip.
4. Search the card's transactions for a **refund** from that merchant after the return date. If one exists, the merchant has paid: deny.
5. Otherwise recommend a credit of the slip's refund amount. For a partial return, only the returned items are credited.

## Common mistakes

- Crediting the whole purchase when only part was returned.
- Missing a refund that posted a few days after the return.
